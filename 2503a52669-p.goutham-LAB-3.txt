Example:
Input: 5

CODE:

def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

print(factorial(5))
print(factorial(3))
print(factorial(0))

Examples:
Input: 153 → Output: Armstrong Number
Input: 370 → Output: Armstrong Number
Input: 123 → Output: Not an Armstrong Number

Now generate the Python function and test it with these examples.

CODE:

def check_armstrong(num):
    digits = str(num)
    power = len(digits)
    total = sum(int(digit) ** power for digit in digits)

    if total == num:
        return "Armstrong Number"
    else:
        return "Not an Armstrong Number"


print(check_armstrong(153))
print(check_armstrong(370))
print(check_armstrong(123))

Task:

PROMPT:

Write an optimized Python program to classify a number as Prime, Composite, or Neither.

Instructions:
1. Use a simple and efficient method.
2. Validate the input.
3. Numbers less than 2 should be classified as Neither.
4. Use a loop only up to the square root of the number.
5. Give sample inputs and outputs.
6. Keep the code easy to understand.

CODE:


def classify_number(n):
    if not isinstance(n, int):
        return "Invalid Input"

    if n < 2:
        return "Neither"

    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return "Composite"

    return "Prime"


print(classify_number(7))
print(classify_number(10))
print(classify_number(1))
print(classify_number(15))
print(classify_number("10"))

PROMPT:

Write a simple Python function to check whether a given number is a perfect number. Return "Perfect Number" or "Not a Perfect Number".

CODE:

def check_perfect(num):
    total = 0

    for i in range(1, num):
        if num % i == 0:
            total += i

    if total == num:
        return "Perfect Number"
    else:
        return "Not a Perfect Number"


print(check_perfect(6))
print(check_perfect(28))
print(check_perfect(10))
print(check_perfect(1))
